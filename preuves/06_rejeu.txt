# Le simulateur dépose les journées dans data/landing/ ; c'est le deployment Prefect
# 'daily-batch-landing' (scrutation toutes les 30 s, un run à la fois) qui les traite.
# Les journées du 2026-04-01 au 2026-04-06 ont été rejouées plus tôt de la même façon.
# Les logs des conteneurs sont en UTC (heure locale = UTC + 1).
# À lire : chaque « Aborted submission ... non-pending state » est un tick de scrutation
# annulé parce qu'un lot est déjà en cours (limite de concurrence à 1, CANCEL_NEW).
# Les feedbacks augmentent avec le rejeu : quand un disque tombe en panne le jour J,
# toutes ses prédictions depuis le 1er avril reçoivent leur vraie RUL. Les survies à J+90
# n'apparaîtront qu'au-delà du 30 juin (horizon de 90 jours après les premières prédictions).
